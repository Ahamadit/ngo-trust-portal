# ngo-trust-portal
A responsive NGO &amp; Trust Management Portal built with PHP, MySQL, HTML, CSS, JavaScript, and Bootstrap. The platform provides an easy-to-use interface for managing trust information, activities, services, events, and other organizational content. <br>
🌟 About the Project

NGO Trust Portal is a modern web application developed to provide a seamless digital presence for an NGO/Trust. The platform allows visitors to easily explore the organization, understand its work, access important resources, and find donation and contact information.

The project also includes a dedicated Admin Panel that allows authorized administrators to manage website content dynamically.

🌐 User Side

Visitors can access:

🏠 Home — Attractive homepage with dynamic banners
ℹ️ About Us — Organization information and mission
🤝 What We Do — Activities, services, and initiatives
📞 Contact Us — Contact and enquiry information
📥 Downloads — Important documents and resources
❤️ Donate Now — Donation-related information
🔐 Admin Panel

The admin panel provides easy content management for:

📊 Dashboard
ℹ️ About Us Management
🤝 What We Do Management
🖼️ Banner Management
📥 Download Management

Administrators can add, update, and delete website content without modifying the main website code.

💻 Technologies Used

Frontend: HTML5, CSS3, JavaScript, Bootstrap

Backend: PHP

Database: MySQL

Development: XAMPP, Git & GitHub

✨ Key Highlights
Professional and responsive design
Mobile-friendly user interface

Admin dashboard
Banner management
Document upload and download

CRUD functionality
🎯 Project Goal

The goal of this project is to create a reliable and easy-to-manage online platform that helps an NGO/Trust communicate its work effectively with visitors while providing administrators with complete control over website content.
